# العالم الإلكتروني — النسخة الجديدة

## النشر
ارفع المجلد أو ZIP إلى Netlify Drop.

## تفعيل الذكاء الاصطناعي
في Netlify: Project configuration → Environment variables → أضف:
- OPENAI_API_KEY = مفتاح OpenAI الخاص بك
- OPENAI_MODEL = gpt-6-astra (اختياري)
ثم أعد النشر.

لا تضع مفتاح OpenAI داخل index.html. مفتاح API يجب أن يبقى في Environment Variables.

## البيانات والأسعار
الموقع يعرض فقط المنتجات التي لها مصدر وسعر موثق ضمن البيانات الحالية. الأقسام التي لا يوجد لها سعر موثق تبقى منفصلة بدون بيانات وهمية.


Restaurant data added from current published Iraqi restaurant menus: Keko Food Baghdad and Al Saniour Baghdad. Prices are copied from their published menus; images point to the restaurants' own image files.
