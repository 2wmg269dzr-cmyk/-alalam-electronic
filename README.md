# العالم الإلكتروني — النسخة المتحركة

- تصميم أسود وذهبي متحرك ومريح للموبايل.
- أقسام مستقلة.
- أسعار المنتجات المدخلة مأخوذة من مصادر عراقية منشورة وقت إعداد النسخة.
- الطلبات عبر واتساب الإدارة فقط.
- لا يوجد حقل بريد إلكتروني.
- موسيقى هادئة مولدة داخل المتصفح عبر Web Audio وتبدأ بعد ضغط المستخدم على دخول.
- مساعد AI عبر Netlify Function `/api/ai`.

## تفعيل الذكاء الاصطناعي
في Netlify: Site configuration → Environment variables أضف:
`OPENAI_API_KEY`
واختيارياً:
`OPENAI_MODEL=gpt-6-astra`

لا تضع مفتاح API داخل `index.html`.
